## 二、设计决定

| # | 事项 | 决定 | 状态 |
| --- | --- | --- | --- |
| D1 | 时代设定 | 当代藏区 | 已定 |
| D2 | 地图结构 | 长期：分段驻扎，一处待数日后转场。**当前只做一张地图**，转场与多地图在核心循环验证后再议 | 已定 |
| D3 | 牲口种类 | 当前只有牛（牦牛）。羊等其他种类后续再加，群体行为参数按种类独立配置 | 已定 |
| D4 | 一天长度 | **实时 30 分钟（1800 s）**。刻意慢：30 分钟的一天是"一段时光"而非"一个关卡"，大部分时间无事发生。不提供快进。理由与时段划分见 `DAY_CYCLE.md` §0–§1 | 已定 |
| D5 | 牲口的丢失与死亡 | **会丢，会死，尽量真实。** 天黑未归栏的牲口次日出现在地图某处需寻回。**死亡唯一来源：连续两晚未归栏，第二晚 25% 概率遭狼。第一晚绝不死**（玩家须有一整天的挽回窗口）。悬崖坠落与饥饿致死明确不做。详见 `DAY_CYCLE.md` §5 | 已定 |
| D6 | 产出与货币 | 单一货币（现金）。牲口按存栏产出奶与毛，奶、毛与牲口本身均可出售换取现金 | 已定 |
| D7 | 惊吓机制 | 群体有惊吓值。玩家移动越快施压越强、效率越高，但越易冲散群体。载具因此是取舍而非纯数值升级：步行稳而慢，骑马居中，摩托快而易惊群 | 已定 |
| D8 | 养成范围 | 现金用于扩群、购置载具、升级住宅。无作物、无季节、无好感度系统 | 已定 |
| D9 | 地标功能 | 玛尼石堆、佛塔、寺院承担导航、存档、地图解锁、委托发布等功能。宗教场所不做交易；买卖放在牧民帐篷与村镇 | 已定 |
| D10 | 休闲的定义 | 休闲指操作量少、节奏舒缓，不指后果轻。允许真实的失去。核心动词是"牧"而非"赶"或"看"：短期不管没事，长期不管牛会慢慢散，玩家一天里自然起身几次 | 已定 |
| D11 | 操作模型 | 玩家不直接控制牛，只通过施压影响。三种施压：走近（轻、被动）、吆喝（近距离、连续、按键切换）、乌尔朵（远距离、离散）。吆喝与乌尔朵是同一机制：源点 + 半径的**区域压力**，只影响半径内的牛。详见 `docs/Herd_BEHAVIOR.md` §6 | 已定 |
| D12 | 草场系统 | 地形覆盖网格数据层，每格有草量与退化值。牛按草量决定吃与走，草场按日恢复，过牧退化。详见 `docs/Herd_BEHAVIOR.md` §4 | 已定 |
| D13 | 头牛 | 群体聚合力指向头牛而非质心。头牛负责挑草场与傍晚认路归栏。头牛丢失后群分裂，隔夜自动产生新头牛。详见 `docs/Herd_BEHAVIOR.md` §3 | 已定 |
| D14 | 灰盒美术 | M3 前不引入外部模型：人物、牦牛、草、远山、围栏全部用引擎原生几何体在代码里拼（`*_body.gd`、`grass_field.gd`、`mountains.gd`、`pen.gd`）。Blender 资产与 LFS 到 M6 再用 | 已定 |
| D15 | 调试入口 | 灰盒期所有验证走命令行参数（`--time` `--screenshot` `--shot-delay` `--player-at` `--log-positions` `--test-sling` `--test-drive`），不开编辑器也能截图与跑数值。见 `docs/STATUS.md` | 已定 |
| D16 | 起始配置 | 起始 1 头头牛 + 4 头普通牛。起始现金推迟到 M5 与定价一起定（不卡 M3） | 已定 |
| D17 | 天黑宽限 | `time_of_day` 到 1.0 后给 60 s 宽限再结算，期间天继续黑下去。把硬截止变软截止，避免傍晚变成抢时间。详见 `DAY_CYCLE.md` §3.4 | 已定 |
| D18 | 挂机安全 | 玩家离开十分钟回来，群不出事。**任何"玩家不管就会出事"的白天机制都不做**（白天的狼、牛走出地图等）。危险只存在于夜里 | 已定 |
| D20 | 群的形态 | 牛群有两档：吃草时散开（摊薄草场压力），头牛有目的移动或被赶时收拢成一团跟着走。不用一套参数硬凑。详见 `Herd_BEHAVIOR.md` §5.1 | 已定 |
| D21 | 放牧原理 | 施压模型按低压力放牧（low-stress stockmanship）校准：逃离区随情绪变大、平衡点在肩部、撤压有奖励、单头惊跑不连锁。不做教学，让规律自己教玩家。详见 `Herd_BEHAVIOR.md` §6.0 §6.5 | 已定 |
| D19 | 存档时机 | 结算后 + 退出时（含 `time_of_day`，可中途续玩）+ 玛尼石堆手动。**不做自动定期存档**，它与"真实的失去"相冲 | 已定 |
