## 1. 一句话

一款当代藏区背景的 3D 低多边形放牧游戏。玩家是牧人，白天守着牛群吃草，走远了吆喝两声、甩一颗石头把它带回来，傍晚陪头牛把群带回围栏，一天天把群养大。

## 2. 目标与非目标

**目标**

- 提供一段安静、舒缓、操作稀疏的放牧体验，玩家愿意坐着看牛五分钟而不觉得无聊。
- 牛群是可信的：有个体、有性格、会自己找草、会自己回家、会真的丢和死。
- 一条清晰的多日成长线：现金 → 扩群 / 载具 / 住宅，升级带取舍。
- 藏地场景作为氛围与功能存在，不说教。
- 作为第一个 Godot 项目，在 M3 前跑通引擎全部基础能力。

**非目标**（明确不做，见 DECISIONS 第四节）

- 作物、季节、NPC 好感度
- 战斗
- 剧情驱动的主线
- 多人

## 3. 目标玩家与体验承诺

**玩家画像。** 喜欢《牧灵奇旅》《Spiritfarer》这类慢节奏游戏；对星露谷式经营有兴趣但嫌它忙；对藏地风物有好奇心。会在晚上开半小时放松。

**体验承诺。** 每一局（一天）玩家应当经历：

1. 清晨出栏，牛群自行散开吃草，玩家找个坡坐下
2. 中段几乎无事，偶尔有一头牛走远或走向危险，甩一颗石头
3. 傍晚光线变暖，头牛开始往回走，玩家起身把掉队的带上
4. 天黑入栏，结算，看一眼明天能买什么
5. 间或有一天出事：一头没回来，或者死了一头。玩家会记得那头牛

**反承诺。** 玩家不应经历：倒计时、任务列表、弹窗奖励、连续失败惩罚、必须持续操作的段落。

## 4. 核心循环

### 4.1 日循环（一局 30 分钟实时，D4；时段划分见 `DAY_CYCLE.md` §1）

```
出栏 → 放牧（自主 + 偶尔干预）→ 傍晚归栏 → 结算 → 商店 → 睡觉 → 次日
```

### 4.2 多日循环

```
现金积累 → 扩群 / 载具 / 住宅 → 群更大、走更远、草场压力更大 → 需要更好地选草场
```

草场系统（BEHAVIOR §4）让"往哪带"成为以天计的决策层。

## 5. 系统需求

每项列需求与验收标准。P0 = MVP 必须，P1 = 完整版，P2 = 后续。

### 5.1 玩家与相机 · P0

- 第三人称角色，步行 / 奔跑两档。
- 固定俯角跟随相机（T10），可转水平方向。
- 远观：Tab 手动切换远 / 近，静止 3 s 也自动拉远，移动时拉回（BEHAVIOR §6.4）。
- 键鼠与手柄同时支持（T11）。

验收：新玩家不看说明能在 30 s 内学会移动与转视角；拉远/拉回无突变。

### 5.2 施压、吆喝与乌尔朵 · P0

- 身位：走近只轻微避让，奔跑才惊牛（BEHAVIOR §6.1）。
- 吆喝：按键切换，以玩家为中心 8 m 的区域压力，近距离连续驱赶（BEHAVIOR §6.2）。
- 乌尔朵：瞄准落点，射程 4–40 m，落点 6 m 内的牛背离落点移动并获得惊吓；有冷却（BEHAVIOR §6.3）。
- 两者是同一机制（区域压力），只影响半径内的牛，其余靠聚合跟上。

验收：站在 30 m 外能用两三颗石头把一头走远的牛送回群；从群后吆喝跟着走，群整体前移不散；连续甩石会把牛惊散。

### 5.3 牛群 · P0

完整规格见 BEHAVIOR §1–3、§5。本文只列硬要求：

- 起始 1 头头牛 + N 头普通牛（N 待定，暂定 4），上限 50（T13）。
- 每头牛有持久的性格参数与外观差异（花色、体型微差），可被认出。
- 头牛负责挑草场与傍晚归栏。
- 惊吓可传染。

验收：玩家不操作，牛群 5 分钟内不出事、不聚成一团、不排成一列、不全体同向；15 分钟内至少一头合群低的牛明显走远；傍晚头牛自行往围栏走且大部分牛跟随。

### 5.3.1 伙伴感 · P0（M3.5，规格见 `Herd_BEHAVIOR.md` §10）

M2 交付的是"一群可信的牛"，还不是"我的那几头牛"。补四件事：

- 起始五头牛配置**鲜明习惯**，不再纯随机（一头稳重头牛、一头贪吃爱掉队、两头喜欢结伴、一头逐渐亲近玩家）。
- **身体表达**：低头吃草、抬头张望、卧下。REST 与 ALERT 现在只存在于代码里，玩家看不见。这一项对生命感的贡献最大。
- **固定同伴**：偏好的伙伴对，会一起休息。只调高合群做不到这件事，那只会让它更贴头牛。
- **对人的熟悉与信任**（D22）：认呼唤、愿意靠近。不是好感度数值，无 UI，不要求每天逐只刷互动。

验收：玩家玩过两三个游戏日后，不看调试面板，能说出"这头通常会怎样"，
并能发现自己的照料让某头牛发生了变化。

### 5.4 草场 · P0（数据层）/ P1（可视化）

- 网格数据层，每格草量与退化值（`GRASSLAND.md`）。
- 牛按草量决定吃与走。
- 每日结算时恢复；过牧退化。
- P1：草量映射到草的着色与高度。

验收：同一块草场连放三天，牛群明显向外扩散；第四天起放别处，一周后原地恢复。

### 5.5 昼夜与时间 · P0

- 单一全局时钟（T17）驱动光照、牛群情绪曲线、结算。
- 时间只靠光线与天空表现，**无钟表 UI**。
- 天黑判定为一天结束。

验收：玩家能在不看任何 UI 的情况下说出"大概是下午了"。

### 5.6 归栏与结算 · P0

- 围栏为一个区域，天黑时区域内的牛计入存栏。围栏有实体栅栏与自动开合的门（BEHAVIOR §8）。
- 结算：存栏产出奶与毛入库（P0 只记数量，P1 才可出售）。
- 未入栏的牛进入走失流程（5.7）。

验收：结算界面一屏，三秒看完；无任何"完成"字样。

### 5.7 走失与死亡 · P0（走失）/ P1（死亡）

- 走失：天黑未归的牛次日出现在地图某处（偏向它最后位置附近的高草量格），保持吃草，玩家可找回。
- 死亡：连续两晚未归栏，第二晚 25% 概率遭狼（D5，详见 `DAY_CYCLE.md` §5.2）。第一晚绝不死。死亡不可逆，牛从存档移除，现场留痕。
- 头牛丢失后的群体分裂与新头牛产生见 BEHAVIOR §3。

验收：走失的牛能在次日 3 分钟内被找到；死亡有明确的现场（尸骨或痕迹），玩家知道发生了什么。

### 5.8 经济与商店 · P1

- 单一货币现金（D6）。
- 奶、毛、活牛可出售。价格固定或小幅波动（待定）。
- 商店在牧民帐篷 / 村镇，售卖：牛、载具、住宅升级。
- 起始现金待定。

验收：正常游玩下第 3–4 天能买第一头牛，第 8–12 天能买马（数值待调）。

### 5.9 载具 · P1

- 马：速度中，惊吓中，需要上下马动作。
- 摩托：速度高，惊吓高，燃料或磨损作为使用成本（待定，也可不加）。
- 载具是取舍而非纯升级（D7）。

验收：三种方式各赶一次群，玩家能说出各自好在哪、坏在哪。

### 5.10 住宅 · P1

- 帐篷 → 土房 → 带院的房子（暂定三级）。
- 每级带一个功能性效果（待定，候选：储奶容量、围栏容量、次日出栏时间提前）。
- 不做装饰性自定义。

验收：每次升级玩家能说出它改变了什么玩法。

### 5.11 地标与委托 · P1（地标）/ P2（委托）

- 玛尼石堆：路标、存档点。
- 佛塔：地图区域解锁、快速移动点。
- 寺院：委托发布，由僧人 NPC 给出。委托复用赶群机制：寻牛、押运、赶往指定草场。
- 宗教场所不做交易（D9）。

验收：新玩家第一天不看地图能靠地标回到围栏。

### 5.12 存档 · P0

- JSON，带 `save_version`（T15）。
- 每日结算后自动存档；玛尼石堆手动存档（P1）。
- 存：日期、现金、库存、每头牛（性格、位置、状态、是否头牛）、草场网格、住宅等级、载具。

验收：读档后牛群位置、性格、草场状态与存档前一致。

### 5.13 UI 原则 · P0

- 白天游戏画面无常驻 UI。
- 结算与商店是唯一的全屏界面，一屏一事。
- 所有文本经 `tr()`，首发中文，预留英文（T18）。
- 无成就、无任务追踪、无小地图（地标承担导航）。

## 9. 美术与音频方向

**视觉。** 低多边形，平面着色，单张调色板贴图。色彩取自高原：草地偏黄绿而非饱和绿，天空大且亮，远山灰蓝。牦牛以黑为主，个体有白斑差异。当代物件（摩托、太阳能板、经幡）自然混入。

**光照。** 一天的光色变化是主要的时间表达手段，也是最重要的美术投入。清晨冷白、正午硬亮、傍晚暖橙、入夜深蓝。

**音频。** 环境为主：风、草、牛铃、远处的牛叫。无背景音乐或极稀疏。乌尔朵有清晰的甩与落地声。傍晚可有远处寺院的号声作为时间提示（自然存在，非 UI）。

**参考。** 《牧灵奇旅》的群体运动与山地尺度；Kenney / Quaternius 的资源风格。

## 10. 风险

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 牛群行为调不出"可信"的感觉 | 核心体验不成立 | M2 单独留充足时间；参数全部数据化便于快速迭代；先调一头牛的节奏再调群 |
| 太放松变成无聊 | 留存差 | 草场压力与真实的失去提供长线张力；MVP 阶段就找外部玩家测 |
| 3D 光照与后处理调不好，画面像作业 | 第一印象差 | M3 后专门一周调一天的光色；参考现成低多边形项目的设置 |
| 相机手感 | 持续的不适 | M1 就定型，多种俯角快速对比 |
| 范围蔓延 | 做不完 | 非目标列表 + 分期 + "M3 前不做打磨" 三条硬规则 |
| 单人开发的美术瓶颈 | 进度 | 低多边形 + 免费资源起步，M6 才考虑自制模型 |

## 12. 成功标准

**MVP。** 三个测试玩家中至少两人在一局结束后主动开第二局，并且能不看提示说出至少一头牛的特点。

**完整版。** 玩家能玩满十天不弃；能说出三种赶牛方式各自的取舍；至少一次因为失去一头牛而产生情绪。

**长期。** 玩家描述这个游戏时用的词是"放松""好看""那头牛"，而不是"任务""刷"。
